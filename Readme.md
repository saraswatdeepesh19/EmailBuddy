# Email Buddy

Email Buddy is a simple web-based email editor with formatting tools, color selection, and preview/send functionality.

## Features

- Select recipient from dropdown
- Add subject and title
- Rich text formatting: Bold, Italic, Underline, Strikethrough, Highlight, Bullet List, Numbered List
- Color picker for text
- Preview and send email (HTML format)
- Responsive and modern UI

## Project Structure

## Getting Started

1. Open `html/email.html` in your browser.
2. Use the toolbar to format your email.
3. Click **Preview** to see the formatted email.
4. Click **Send Email** to log the email content, subject, and recipient in the console.

## Customization

- **Styling:** Modify `css/email.css` for custom colors, spacing, and layout.
- **Functionality:** Update `js/mail.js` to add more formatting options or integrate with an email API.
